# 🧠 Modern Python Quiz App (GUI)

> **"Test your knowledge with a sleek, modern interface."**
A high-performance quiz application built using Python and the CustomTkinter library.


## 📄 About The Project
This project is part of my **Python Alphabet Challenge**. It demonstrates how to build a modern, responsive Graphical User Interface (GUI) that looks significantly better than standard Tkinter applications.

The **Quiz App** features a dynamic question-loading system, a real-time progress bar, and an automated scoring engine with personalized feedback.

## 🚀 Features
* ✅ **Modern UI:** Built with `CustomTkinter` for a macOS/Windows 11 dark-mode look.
* ✅ **Dynamic Progress:** A visual progress bar that tracks your journey through the quiz.
* ✅ **Smart Scoring:** Instant result calculation with performance-based feedback.
* ✅ **Interactive Elements:** Smooth radio button selections and hover effects.
* ✅ **Responsive Design:** Clean layout with auto-wrapping text for long questions.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **GUI Library:** `CustomTkinter` (Modernized Tkinter)
* **Logic:** Dictionary-based Question Mapping & Object-Oriented Programming (OOP).
